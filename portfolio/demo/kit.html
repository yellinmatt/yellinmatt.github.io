The Claude OS Kit

One operating system for a working life, packaged four ways for four different readers. Each edition ships a handbook, a deck, a set of blank templates, and a first-run script that interviews the reader instead of handing them a manual.

EditionWritten forWhat is different about itShips
Edition 01EnterpriseA private equity firmInformation barriers between deal teams, four data classes, named approval authority, a shared memory that stops at the wall.16-slide deck, 16-page handbook
Edition 02Work accountA locked-down machineThree files you paste in. No install, no terminal, no admin rights assumed anywhere in it.3 files, paste and go
Edition 03BeginnerSomeone who has never opened a terminalAsks one question at a time and never makes the reader type a file path. The first run interviews you instead of handing you a manual.6 templates, guided start
Edition 04AdvancedSomeone who already runs oneThe introductory layer cut out entirely. A one-page landscape reference, a twenty-slide deck, and an annotated config twin.Palette sampled, not invented

Decisions carried across all four
  1. One law fileEverything else points at it, so there is never a second answer.
  2. Memory in tiersA hot kernel read every time, a cold trail read on demand.
  3. Suggest, then actIrreversible work is proposed before it is done, every time.
  4. Build-time layout gatesTwo of them, and either one fails the build rather than shipping a page that overflows.

The build refuses to finish if a single text box overflows its container, which is the only reason the pages are square.
