Documentation kit · Edition four

The Claude OS Kit

One operating system for a working life, packaged four different ways for four different people. Every edition ships a handbook, a deck, a set of blank templates, and a first-run script that interviews the reader instead of handing them a manual.

Edition 01

Enterprise

Multi-user install with information barriers, a four-tier data classification, and named approval authority.

16-slide deck · 16-page handbook
Edition 02

Work account

A three-file install for a locked-down machine. Folder pre-flight, cost gates, a worklog memory model.

3 files · paste and go
Edition 03

Beginner

Written for someone who has never opened a terminal. Asks one question at a time and never makes them type a file.

6 templates · guided start
Edition 04

Advanced

No introductory layer at all. A one-page landscape reference, a twenty-slide deck, and an annotated config twin.

Palette sampled, not invented
