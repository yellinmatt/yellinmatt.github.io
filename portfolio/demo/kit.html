The Claude OS Kit

One operating system for a working life, written out four times for four different readers. Each edition ships a handbook, a deck, a set of deliberately blank templates, and a first-run script that interviews the reader instead of handing them a manual.

Decisions carried across all four
  1. One law fileEverything else points at it, so there is never a second answer.
  2. Memory in tiersA hot kernel read every time, a cold trail retrieved only on demand.
  3. Suggest, then actIrreversible work is proposed before it is done. Every time, including when it is obvious.
  4. Build-time layout gatesTwo of them, and either one fails the build rather than shipping a page that overflows.

The build refuses to finish if a single text box overflows its container, which is the only reason the pages are square.
