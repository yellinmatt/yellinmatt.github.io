04

Folders and files

One folder tree holds everything. Each folder has one job and one rule. Pick one.

Four rules for every file

Letters only sort

The letter in A. System orders Finder. Rules name the concept, so a folder can be re-lettered without breaking anything.

One source of truth

Each kind of thing has one home. A copy elsewhere is a bug, not a backup.

Nothing is deleted

A replaced file moves to Trash with a manifest line saying what it was and why it moved.

Folders write, boards read

Each project keeps its own state. Status boards are generated from it and never edited by hand.

Where each kind of thing lives

EventsGoogle Calendar, read together with Apple Calendar
Tasks and deadlinesApple Reminders
Knowledge and project stateMarkdown files in this tree
